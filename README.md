## 網站內自訂錯誤代碼

| 代碼 | 意義 |
|:--- | :---|
| SITE-DB-R001 | 自訂每日讀取上限已達 |
| SITE-DB-R002 | Firestore 配額耗盡（RESOURCE_EXHAUSTED） |
| SITE-DB-R003 | 單次請求讀取預算不足 |
| SITE-DB-W001 | 自訂每日寫入上限已達 |
| SITE-DB-W002 | Firestore 寫入配額耗盡 |
| SITE-DB-W003 | 單次請求寫入預算不足 |
| SITE-IMG-C001 | 測驗圖片儲存（R2）尚未設定 |
| SITE-IMG-C002 | 測驗圖片儲存服務異常 |
| SITE-IMG-U001 | 圖片上傳失敗（服務端） |
| SITE-IMG-D001 | 圖片刪除失敗（服務端） |

一般使用者／老師看到的訊息統一為：**系統忙碌中，請洽管理人員**（錯誤代碼僅管理員可見）。

## Firebase 資料庫架構

| 匯出 | 用途 | 環境變數（Admin） | 公開前端 |
| :--- | :--- | :--- | :--- |
| `adminDb`／`contentDb`（core） | 課程、學生、點名、成績、帳號、**部落格、網站公告、考試日期** | `FIREBASE_CORE_*`（相容舊 `FIREBASE_*`） | `NEXT_PUBLIC_FIREBASE_CORE_*` |
| `quizDb` | 測驗、繳交、課程問卷 | `FIREBASE_QUIZ_*` | — |

`contentDb` 為語意別名，**固定等同 core**（不需 `FIREBASE_CONTENT_*`）。未設定 QUIZ 憑證時，`quizDb` 會暫時回退使用 core。
